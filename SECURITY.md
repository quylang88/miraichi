# Security Policy

Security guidelines and vulnerability reporting instructions for Miraichi.

## Purpose
This document provides instructions on how to report potential vulnerabilities and outlines the security standards for the repository.

## Status
- **Status**: Draft

## Scope
Applies to all code, configurations, deployments, and dependencies in the Miraichi monorepo.

## Rules & Guidelines
- Do not commit secrets, private keys, or actual database passwords to the repository.
- Use the `.env.example` file to denote required parameters.
- Report all vulnerabilities directly to the project team rather than opening public GitHub issues.
