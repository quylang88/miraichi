# Prediction Output Envelope

* **Status**: Active
* **Date**: June 23, 2026

---

## 1. Boundary Context
This document specifies the structure of prediction outputs returned by the local AI service. The output envelope encapsulates predicted outcomes alongside audit traces, status indicators, and warning flags, ensuring that all downstream applications (API, UI, Betting Engines) consume predictions in a standardized and traceable format.

---

## 2. Envelope Schema Contract
Every prediction generated by the AI service must conform to the following schema:

| Field Name | Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `predictionId` | String | Unique UUID for this prediction execution | `pred-alpha-998877` |
| `matchId` | String | Reference to the generic match fixture | `match-alpha-001` |
| `competitionId` | String | Context competition ID | `competition-alpha` |
| `seasonId` | String | Context season ID | `season-alpha-2026` |
| `generatedAt` | String | ISO-8601 UTC timestamp of inference execution | `2026-06-23T22:45:00Z` |
| `engineMode` | String | Execution runtime mode (`mock`, `rule_based`, `local_ml`) | `mock` |
| `predictionAvailable` | Boolean | True if inference completed successfully | `true` |
| `confidenceLabel` | String | High-level category tag; must not use mathematical formulas | `mock-medium` |
| `outputSummary` | String | Short, plain-text summary of the outcome | `Outcome leans home advantage based on mock data.` |
| `trace` | Object | Nested audit tracing block (see section below) | `{ ... }` |
| `warnings` | Array | Quality warnings detected during execution | `["odds_stale_warning"]` |

---

## 3. Tracing Block Schema
The nested `trace` block contains the metadata required to verify data lineage from the sports feed to the prediction engine:
* `inputCandidateId`: Links back to the exact input candidate processed.
* `workerRunId`: Links back to the background worker job that cached the raw data.
* `engineVersion`: The version of the `apps/local-ai` service code.
* `modelChecksum`: Optional SHA256 checksum of the local model weights (when a real model is approved).

---

## 4. Strict Prohibitions
To adhere to the owner-approved gates:
1. **No Probability Formulas**: The envelope must not return probability decimal outputs (e.g., `homeWins: 0.65`) unless approved via ADR.
2. **No Value Ratings**: It must not score bets or compare odds (e.g., "value bet detected").
3. **No Risk Allocations**: It must not suggest stake percentages, bankroll values, or recommend wagering amounts.
