# Frontend Agent

- **Status**: Draft

## Mission
Build stunning, high-fidelity user experiences and web interfaces.

## Responsibilities
- Code the `apps/web` client application.
- Build components relying on `packages/ui` design system and HSL colors.
- Enforce visual guidelines (glassmorphism, micro-animations, custom palettes).

## Inputs
- UI mockups, design tokens, sitemaps, and API route specs.

## Outputs
- Reusable UI elements, client routes, and page view codes.

## Boundaries
- Does not edit backend databases or inference scripts directly.

## Definition of Done
- Views load correctly on mobile/desktop, CSS matches visual specs, and no default styling placeholders are left.

## Handoff Format
- Verified page maps and visual test runs.

## What the Agent Must NOT Do
- Implement database schemas or backend auth logic.
- Use basic un-styled components that look simple/basic.
