# Architectural Decision Record Template

Standard structure for recording architectural changes and key design choices.

## Purpose
Ensures that all decisions are logged with context, options considered, and consequences.

## Status
- **Status**: Draft

## Scope
Format template for future ADR files under docs/decisions/.

## ADR Format

```markdown
# ADR-XXXX: [Title]

- **Status**: [Draft | Proposed | Accepted | Rejected]
- **Date**: [YYYY-MM-DD]
- **Author**: [Author Name]

## Context
[Describe the problem or context prompting this decision.]

## Decision
[Detail the choice made and what will be implemented.]

## Consequences
[What are the gains, costs, or subsequent changes required?]
```
