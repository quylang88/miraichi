# Git Branch Strategy

Rules for git branching, tracking, and naming.

## Purpose
Ensures a clean git history and avoids conflicts in the monorepo.

## Status
- **Status**: Draft

## Scope
Directly outlines git workflows for all developers and agents.

## Branch Naming Conventions
- Features: `feat/[name]/[feature]`
- Hotfixes: `fix/[name]/[issue]`
- Documentation: `docs/[name]/[update]`
