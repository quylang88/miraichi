# Commit Conventions

Standards for formatting commit messages.

## Purpose
Ensures consistent changelogs and clean semantic histories.

## Status
- **Status**: Draft

## Scope
Commit messages syntax rules.

## Formatting Rules
- Format: `<type>(<scope>): <description>`
  - Types: `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `build`, `ci`, `chore`.
  - Description must be in imperative present tense (e.g. "add competition schema").
