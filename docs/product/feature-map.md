# Feature Map

Functional taxonomy of application capabilities.

## Purpose
Groups features by system modules to organize backlog planning.

## Status
- **Status**: Draft

## Scope
Outlines user-facing capabilities across web, API, AI, and backend processes.

## Feature Hierarchy
- **Match Data API**: Local/manual national-team fixtures and results, source provenance, freshness/staleness status.
- **Today**: Date-first daily match dashboard for finished and scheduled fixtures.
- **Matches**: Competition/date filters, match detail, scheduled/finished grouping.
- **Bet Manager**: Owner-entered bet drafts and history, without automated betting advice.
- **Bankroll Manager**: Manual capital/account ledger records, backup/export, no stake or risk formulas.
- **AI Assist Board**: Deferred `Miraichi AI` surface for the final AI phase only.
