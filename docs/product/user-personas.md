# User Personas

Target user profiles for Miraichi.

## Purpose
Identifies key customer profiles to guide user experience and feature prioritization.

## Status
- **Status**: Draft

## Scope
User behavior descriptions, goals, pain points, and target features.

## Personas
- **The Analytical Fan**: Wants data-driven stats and predictions to form independent match theories.
- **The Casual Bettor**: Seeks a simple bankroll management log to prevent over-betting.
- **The AI Enthusiast**: Eager to test local LLM routing parameters for sports discussions.
