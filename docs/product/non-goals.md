# Non-Goals

Exclusions and items explicitly out of scope for Miraichi.

## Purpose
Prevents scope creep by clearly documenting what the application will *not* do.

## Status
- **Status**: Draft

## Scope
Outlines feature categories and architectures excluded from the product.

## Non-Goals
1. **No Real-Money Betting Gateway**: Miraichi does not process real monetary bets or integrate with real booking cash APIs.
2. **No Proprietary Prediction Models**: The core app provides execution stubs; we do not build proprietary prediction algorithms.
3. **No Support for Non-Football Sports**: Scope is strictly limited to football (soccer).
