# Web Page Map

## Primary Tabs

- `Today`: daily match context and owner summary.
- `Matches`: search and filter configured competitions.
- `Bets`: manual drafts, pending records, and settled records.
- `Bankroll`: point accounts, ledger entries, and backups.

## Secondary Surfaces

- Match detail is a sub-view, not a primary tab.
- Add/edit/review flows use sheets scoped to owner-entered records.
- Settings remain shell preferences and do not create a fifth primary tab.

All factual match data comes from the Miraichi API.
