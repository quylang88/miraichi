# Web Page Map

Sitemap and view boundaries for the Miraichi web client.

## Purpose
Visualizes and describes routing levels and access keys for the client app.

## Status
- **Status**: Draft

## Scope
Outlines all public and private pages within the frontend client.

## Page Structure
- `/` - Public landing page introducing predictions
- `/dashboard` - Overview of betting progress, prediction history, and current status
- `/predictions` - Aggregated list of upcoming matches across all active competitions
- `/bets` - Active user bet slips, odds visualizer, bankroll logs
- `/chat` - AI assistant interface for querying matches, markets, and suggestions
