# Data Contracts

Format rules for inputs and outputs in apps/local-ai.

## Purpose
Ensures consistent schemas for external statistical providers, API requests, and model responses.

## Status
- **Status**: Active

## Scope
Defines model input features and output predictions payload shapes.

## Guidelines
- All contract keys must use generic competition definitions.
- Model response keys must follow naming schemas from packages/shared.
