# Agent Handoff Guidelines

Standards for transitioning work between specialist subagents.

## Purpose
Ensures that state, errors, and current files context are preserved when handing off tasks.

## Status
- **Status**: Active

## Scope
Directly governs transitions between the nine specialist subagents.

## Core Rules
1. **Document Current State**: The sending agent must create a clear summary of what was completed and what failed.
2. **Specify Next Step**: Clearly define the initial instruction for the receiving agent.
3. **No Unstructured Handoffs**: Always use the handoff schema defined in packages/agent-protocol.
