# Naming Conventions

Coding conventions and key domain term standards.

## Purpose
Ensures consistent naming styles across TypeScript, Python, SQL, and Markdown.

## Status
- **Status**: Draft

## Scope
Coding symbols, classes, files, database tables, and configuration parameters.

## Guidelines
- Class names: PascalCase (e.g. `PredictionPipeline`).
- Variable names: camelCase (e.g. `matchId`).
- Database columns: snake_case (e.g. `competition_id`).
- Environment variables: UPPER_SNAKE_CASE (e.g. `DATABASE_URL`).
